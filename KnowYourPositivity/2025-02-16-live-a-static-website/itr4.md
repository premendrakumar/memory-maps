# In Summary: Sasta & Tikau Upay (GitHub Pages via main)
- 1️⃣ GitHub pe jaa → Repo → Settings → Pages
- 2️⃣ Branch select kar → main → / (root)
- 3️⃣ Save kar de → 🚀 Ho gaya deploy!

# Ab pata kaise karein ki live hua ki nahi aur hua bhi toh kaha.🤔🏃‍♂️‍➡️🚀🚀🚀🚀🚀🎯

Bhai **check karne ka sasta aur tikau tareeka** ye hai:  

### **1️⃣ GitHub Pages URL Dekho**  
Jaise hi **Step 3** complete kiya tha (**Save kiya**), **thoda scroll** karke **GitHub Pages section** me **deployed URL** dikhega.  
🚀 **Example URL:**  
```
https://<your-github-username>.github.io/<your-repo-name>/
```
Bas ye **URL khol ke dekh lo**!  

### **2️⃣ Force Refresh (CTRL + SHIFT + R)**
Agar **latest changes nahi dikh rahe**, to **force refresh** karo ya **incognito mode** me open karo.  

### **3️⃣ Manually Check via Terminal (Optional)**
```sh
curl -I https://<your-github-username>.github.io/<your-repo-name>/
```
Agar **`200 OK`** aaya, to site **live hai**!
